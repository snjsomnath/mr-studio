# Screenshots for issues and pull requests

This branch holds only pictures, so they stay off `main` (#737). Add a picture as
`<issue>-<what>.png` at the top level, commit, push, and link it by this branch's commit SHA:

    https://raw.githubusercontent.com/snjsomnath/mr-studio/<sha>/<issue>-<what>.png

Pictures a release note shows still go in `docs/screenshots/` on main. See CONTRIBUTING.md.
