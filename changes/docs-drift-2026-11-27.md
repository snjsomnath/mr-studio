### The Help and the docs catch up with the latest features

The Help window's guides and the developer docs now cover what came in over the last releases (#618): zipped shapefiles and GeoPackages, rasters of values with Dig, well logs and the two stacks of an X-ray glass and a Reveal line; the calibration panel on the controller with building corners; one idle timer for the whole table; the polite OpenStreetMap fetches; Share's size warning; tables that name the MR Studio they need; and the limit on what a table keeps offline. The guides also use the ribbon's real names again (Insert › New layer, Insert › Data file, Present › Screens and calibration…) where they still said Edit or Display tab. For layer authors, the layer contract, the building blocks and the architecture describe `ctx.map.addSprites` and `ctx.map.addStrokes`, and the visualisation framework has a new motion rule (M10) from the Mac demo.
