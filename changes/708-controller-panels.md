### Controller panels with Sunlight's look

The controller now has shared looks for a layer's own buttons and cards: glass buttons, red buttons for anything that deletes, glass cards and a calm "nothing yet" state. Field walk uses them first: Remove this spot and Clear the walk are now red and set apart from Save. The map controls (Reset view, Full screen, Calibrate) have a faint solid edge, so they no longer look switched off. A panel that scrolls now fades at its foot instead of ending in a cut line. Visitors no longer see "Open the table to see live values here"; only the developer page says it.
