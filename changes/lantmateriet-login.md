### The Web map guide explains Lantmäteriet's logins

The Web map guide now says which Lantmäteriet maps need no login (the built-in maps from SLU's open copy) and which do (Lantmäteriet's own Ortofoto Visning and Topowebb). It says where to get the Geotorget login and how to use it as a sign-in (#42). The Lantmäteriet card in Sources and keys says the same.
