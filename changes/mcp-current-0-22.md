### The MCP server knows golden hour and stages made of panels

An LLM designing with the MCP server now finds the sun study's golden hour, and it helps a developer build a controller view from panels before writing code: `check_layer` checks a stage made of panels against the same density budget as the TV, makes sure its control and map panels name the layer's real controls and tools, recognises a layer's own widgets, and asks for their titles in Swedish. `preview_layer` points to the Developer workbench in `/dev`, and the code layer and controller app prompts start from panels.
