# Release notes waiting for the next version

Every pull request adds one file here: a few lines on top (`bump`, `issues`, optional `breaking`),
a `###` title and a short text with a screenshot. On merge to main the "Desktop app" workflow turns
them into the next version and its section in CHANGELOG.md, and removes them.
How to write one: [docs/RELEASING.md](../docs/RELEASING.md).
