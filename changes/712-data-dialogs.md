### Calmer data dialogs

Add data no longer shows a code sample to everyone. The file format is folded behind "Show the file format". The OpenStreetMap wait line now names the service rather than a server: "Waiting for a free turn at OpenStreetMap (8 s)", "Asking OpenStreetMap" or "Asking an OpenStreetMap mirror". The dialogs' close × no longer draws an odd ring when a dialog opens; it shows a clean ring only when you reach it with the keyboard.
