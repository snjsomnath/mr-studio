### The table builds itself when it opens

When presenting starts, and after Reset on the controller, the projected table now opens dark and the place builds itself from its own data. The streets trace in as light lines from the middle outwards, then the buildings fill in and the trees appear, and the dark lifts as the layers fade in. The table's chime plays as it starts. Every table gets this without any setup, because it uses the table's own streets, buildings and trees. It is the new default under Design › Table size and place › Opening, beside "Layers fade in one by one" and "Zoom in". A table without streets or buildings fades in instead, and so does a computer set to reduce motion.
