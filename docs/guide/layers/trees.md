# Trees

## What it shows

Soft green tree crowns, swaying in a light wind.

## Good for

Showing the green in a place, and as a calm part of the map at rest.

## Set it up

1. The table needs its trees: Edit tab, **Add data**, **Trees**, **From OpenStreetMap**, or a file of your own (points, with a crown size if you have one).
2. Add **Trees** from **Add a layer**. It goes under **Map**.
3. Set **Crown size** and how much **Wind** moves them.

## Tips

- OpenStreetMap often misses trees in parks and yards. A city's own tree register is usually more complete.
- The same trees also cast shade in Sunlight and slow the wind in Wind.
