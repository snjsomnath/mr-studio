# Table grid

## What it shows

A glowing grid on the seams between the model's tiles, with a dot at every crossing and ripples running out from the centre.

![The grid on the tile seams](docs/screenshots/191-grid-table.png)

## Good for

Checking that the projection lands exactly on the physical model, and as an eye-catching start.

## Set it up

1. Make sure the table's tile size is set (Table settings, **Size**), or set **Tile size** in the layer.
2. Add **Table grid** from **Add a layer**.
3. Look at the model: every line should sit on a seam. If it does not, calibrate (Display tab, **Calibrate**).

## Tips

- Turn **Pulse** off while you calibrate, so the lines hold still.
