# Wind

## What it shows

How the wind flows between the buildings and through trees: where it speeds up along a street, where it is calm in a courtyard, and which walls it hits.

![Wind ribbons between buildings](docs/screenshots/159-wind-after-ribbons.jpg)

## Good for

Comfort on squares and paths, the effect of a tall building, and why some corners are always windy.

## Set it up

1. The table needs buildings (Insert tab, **Data file**). Trees make it more real.
2. Add **Wind** from **Add a layer**.
3. Set **Wind speed** and **Wind from** (the direction it blows from, in degrees: 270 is west).
4. Under **Show**, choose **Ribbons** (flowing lines), **Particles** or a **Speed map**.
5. On a slower computer, set **Detail** to **Coarse**.

## Tips

- In Gothenburg the strongest winds usually come from the south-west, around 225°.
- **Light the walls the wind hits** makes the facades facing the wind glow, which visitors read at once.
