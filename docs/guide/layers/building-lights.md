# Building lights

## What it shows

Lit windows along the building facades, coming on and going off now and then, as in a city at dusk.

![Lit windows at rest](docs/screenshots/53-at-rest.png)

## Good for

A calm, living look when the table is at rest.

## Set it up

1. The table needs its buildings: Edit tab, **Add data**, **Buildings**.
2. Add **Building lights** from **Add a layer**. It goes under **Map**.
3. Set how many **Windows lit**, from none to all.

## Tips

- A warm **Light colour** looks like homes; a cool white looks like offices.
