# Building blocks

## What it shows

Two example scenes made only from MR Studio's building blocks: "Places that pull" (places drawing people towards them) and "Energy community" (energy flowing between buildings). It runs on made-up data.

![The building blocks demo](docs/screenshots/163-lit-blocks.png)

## Good for

Seeing what the building blocks can do before you make a layer of your own. It is a demonstration, not a layer to show visitors.

## Set it up

1. Add **Building blocks** from **Add a layer**.
2. Choose a **Scene**. **Next step** moves "Places that pull" on.
3. Choose what the **Pointer on the table** does: read values, walk a person, magnify or X-ray.

## Tips

- To make your own layer like this, use **New layer** under **Make your own** on the Edit tab.
