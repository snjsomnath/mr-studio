# Traffic

## What it shows

Cars, taxis and buses with headlights driving the streets, and now and then an ambulance or a fire engine with flashing lights.

![Traffic on the streets](docs/screenshots/201-traffic-table.png)

## Good for

Life on the map while nobody is using the table, and a feel for how busy the streets are.

## Set it up

1. The table needs its streets: Insert tab, **Data file**, **Streets**, **From OpenStreetMap**.
2. Add **Traffic** from **Insert › New layer**. It goes under **Map**, so it runs while the table is at rest.
3. Set **Cars per kilometre of street**. Around 10 looks lively without being crowded.

## Tips

- If no cars appear, the table has no streets yet. The editor says so beside the layer.
- Turn **Headlights** off for a daytime look.
