# Displays, colour and projector calibration

*Make the projection land on the model and look right.*

1. Open the **Display** tab of the editor's ribbon.
2. **Screens**: choose which display is the table (the projector) and which is the controller. **Identify** shows a number on each screen.
3. **Calibrate** puts markers on the table. Move them onto the matching corners of the physical model, from the editor or the controller. The map then lands on the model.
4. **Colour**: boost saturation, contrast and brightness for each display, set midtones and white balance, and save it as a preset. A test card helps.
5. **Layer strength** dims or brightens a single layer on the projector only.
6. **Quality**: Draft keeps a slow computer smooth, Best gives a strong one finer detail.
