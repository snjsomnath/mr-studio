# Share a table, undo and history

*Move a table to another computer, and go back to any earlier state.*

1. **File, Export table** packs the table (settings, data, pictures, calibration) into one `.mrstable` file. Keys never travel in it.
2. On the other computer, **Home, Open a table file** turns it into a new table and says which sources still need keys there.
3. **Undo** and **Redo** (Ctrl+Z and Ctrl+Y, or ⌘Z and ⇧⌘Z) work across the whole editor.
4. The **History** panel lists every change with its time; choose one to go back to it.
5. Tables saved by a newer MR Studio may not open in an older one. Keep every computer on the same version; Home says when a new one is out.
