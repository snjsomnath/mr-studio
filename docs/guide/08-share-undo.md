# Share a table, undo and history

*Move a table to another computer, and go back to any earlier state.*

1. **Share** at the top right of the editor (also **File, Share by email**) packs the table into one `.mrstable` file and opens a new email in your mail app with the file attached. Add who it goes to and send it. If the file is big, your mail app may offer to send it as a link (Outlook does, through OneDrive); that works too. The file stays in Documents, MR Studio, Shared.
2. **File, Export table** saves the same file wherever you choose, to copy by hand. Keys never travel in it.
3. On the other computer, such as the studio PC, double-click the file or choose **Home, Open a table file**. A table that computer does not have yet opens as a new one. If it already has this table, it asks: **Update it** replaces the content, keeps that computer's own calibration and puts the version it had in the Trash; **Keep both** opens it as a second table. If that table is on the screens, it offers **Update when the show stops**: the new version waits, Home says so, and it goes in place when someone stops presenting or at the nightly restart. **Stop and update now** does it at once. It then says which sources still need keys there.
4. **Undo** and **Redo** (Ctrl+Z and Ctrl+Y, or ⌘Z and ⇧⌘Z) work across the whole editor.
5. The **History** panel lists every change with its time; choose one to go back to it.
6. Tables saved by a newer MR Studio may not open in an older one. Keep every computer on the same version; Home says when a new one is out.
