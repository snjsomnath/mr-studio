# Share a table, undo and history

*Move a table to another computer, and go back to any earlier state.*

1. **Share** at the top right of the editor (also **File, Share by email**) packs the table into one `.mrstable` file, says how big it is, and then opens a new email in your mail app with the file attached. Add who it goes to and send it. Over 20 MB it warns that email will likely refuse the file and offers **Show in Finder** (**Show in Explorer** on Windows) first, to send it another way. Some mail apps offer to send a big file as a link (Outlook does, through OneDrive); that works too. The file stays in Documents, MR Studio, Shared.
2. **File, Export table** saves the same file wherever you choose, to copy by hand. Keys never travel in it.
3. On the other computer, such as the studio PC, double-click the file or choose **Home, Open a table file**. A table that computer does not have yet opens as a new one. If it already has this table, it asks: **Update it** replaces the content, keeps that computer's own calibration and puts the version it had in the Trash; **Keep both** opens it as a second table. If that table is on the screens, the update can wait: **Update when the show stops** puts it in when someone stops presenting (or at the nightly restart), and Home says a new version waits until then. It then says which sources still need keys there.
4. **Undo** and **Redo** (Ctrl+Z and Ctrl+Y, or ⌘Z and ⇧⌘Z) work across the whole editor.
5. The **History** panel lists every change with its time; choose one to go back to it.
6. A table remembers the newest MR Studio that changed it. On a computer with an older version it says which version it needs ("This table was made with MR Studio 0.55. This computer has 0.49…"), and offers **Open anyway** when the older version can still read it. Keep every computer on the same version; Home says when a new one is out.
7. A table that brings programs of its own (services, or a team's own layers) asks before they run the first time it arrives: **Run them**, **Open without them** or **Cancel**.
