# Sample data kit

One small, invented district with a file for every kind of data MR Studio reads, plus a few
files that are wrong on purpose. Use it to try the New table wizard, Add data and every layer
without hunting for real data.

Everything is generated by `tools/make_kit.py` (Python standard library only) from the
synthetic district in `sites/sample`, so it is licence-free and reproducible:

```sh
python3 samples/kit/tools/make_kit.py
```

## Where to put the table

Make a new table centred on **lat 57.700, lon 11.970**, **1000 × 600 m**, rotation 0.
Every file below then lands on the table (the sample site `sites/sample` uses the same frame).

| `walkways.geojson` | 137 paths, `highway=footway|path|pedestrian`, `surface` | Your place → Walking paths | Cool paths |
| `streets.geojson` | 40 streets, `highway`, `maxspeed`, `name`, `width` | No Streets row yet (#33). Today: Add data as dataset `roads` | Traffic, base map streets |
| `transit.geojson` | Tram and bus lines with `line`, `mode`, `colour` | Add data as dataset `transit` | Public transport (simulated) |
| `trips.json` | Journeys to the square, walk and walk+tram | Your place → Trips | Mobility |
| `zones.geojson` | 8 polygons with `population`, `green_share`, `noise_db` | Add data | Choropleth / "based on" colours, slideshow slide |

| `sensors.geojson` | 5 sensor points with `sensor_id` | Add data | Points joined to the time series |

| `tables/bike-track.csv` | A moving point: `timestamp,lat,lon,speed_kmh` | Add data | A moving point over time (D4) |
| `tables/activity.csv` | A weekday per place, half-hourly: `place,time,activity` | Add data as dataset `activity` | Place motions that swell with events (orbiters, fireflies, cultural gravity) |

| `masterplan.svg` | A 1000 by 600 plan drawing in six Inkscape layers: boundary, green spaces, routes, new buildings, activity nodes | Add data, a dataset of its own (such as `masterplan`) | Masterplan layer: phases revealed one at a time (#193) |
| `drawing/viewpoints.svg` + `drawing/viewpoints-colour.svg` | White line work in a `Base` group with four viewpoints as layers (what can be seen from a spot), and the same district in colour. | `drawing/underground.svg` | Made-up water mains, district heating and a metro tunnel | Add data as `underground`, then a Masterplan inside a Magnifier or Reveal line | X-ray of what is under the ground (#287, #288) |
| `slideshow/` | Image, two GeoJSON slides and a WMS slide (disabled; needs a key, #42) | Site data `slideshow` | Slideshow layer, manual and timed (#43) |

### Coordinate systems (`crs/`)

| File | Expect |
|---|---|
| `crs/buildings-sweref99tm.geojson` | Names EPSG:3006 in its `crs` member; imports without a question |
| `crs/buildings-sweref99tm-no-crs.geojson` | Projected metres with no `crs`; the editor should ask or guess SWEREF99 TM |
| `crs/trees-sweref99tm-excel.csv` | What Excel saves on a Swedish PC: `;` separators, decimal commas, BOM, columns `N`/`E`. Positions read fine; the `Höjd` height column isn't recognised yet (#47) |
| `crs/terrain-wgs84.tif` | Ground in plain lon/lat (EPSG:4326) |

### Wrong on purpose (`broken/`)

| File | Expect a clear message |
|---|---|
| `broken/buildings-3km-away.geojson` | "None on the table, about 3.1 km north-west" (the case from #32) |
| `broken/buildings-half-off.geojson` | Half on the table; offer to crop |
| `broken/buildings-lat-lon-swapped.geojson` | Detected as swapped; offer to swap |
| `broken/buildings-no-heights.geojson` | No heights (one is the text "about 12 m"); default height used and said so |
| `broken/walkways-are-points.geojson` | Points where lines are needed |
| `broken/trees-no-position.csv` | No position columns |

## Checked against main (548dc67)

Brought in through the editor's Your place step on a blank table at this frame: buildings,
ground (SWEREF99 TM), trees (both CSVs), walking paths and trips all land on the table (the district
runs a little past the table edge on purpose, so 23 buildings and 35 trees are offered for
cropping). Both SWEREF99 TM building files, the 3 km offset, swapped lat/lon, missing heights and
points-as-paths gave the messages listed. Not yet tried in the editor: `buildings-half-off`,
`trees-no-position.csv` and `terrain-wgs84.tif`. Streets, zones, sensors, the time series and the
image overlay have no editor door yet; they're here for the issues that add one.
