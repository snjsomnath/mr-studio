        What's new

        Delete this table?

        Its folder, with its data, pictures and calibration, moves to the Trash. You can put it back from there until the Trash is emptied.

        Delete this recording?

        All of it moves to the Trash, with everything phones sent during it. You can put it back from there until the Trash is emptied.

        Export this recording

        One .mrsession file with the recording and a copy of its table as it was, so it plays on a computer that never had the table. Keys and passwords never go in it.

        Recording details

        This table is already on this computer

        The file is another version of it. Update it to show what the file has; this computer's calibration stays as it is, and the version here goes to the Trash.

            What is this table called?

            Where is the middle of the table?

            Paste a link from Google Maps or OpenStreetMap, or type the coordinates as latitude, longitude. In Google Maps, right-click the spot and click the numbers to copy them.

            How much of the place fits on the table?

            The width on the ground that the table's long side covers.
