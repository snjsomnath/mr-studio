    Calibration

    Line the projected map up with the physical model, so buildings land on buildings. The tool runs on the table itself, where you can see the light on the model.

    1. Start the tool. It appears on the table and names ten corners of the model, one at a time.
    2. Move each projected marker with the mouse or the arrow keys until its light sits on that corner of the physical model. Skip a corner you cannot find.
    3. From six corners on, the model is drawn through the solved camera, so you can see whether it lands.
    4. Save on the table. The calibration is kept in the table's folder.

      Running unattended

      While a table is presented, MR Studio watches it. A window that goes blank or stops answering is reloaded, and a table that stops is started again. A failed graphics card hands over to the processor. None of this shows on the screens.

      For a table that runs for weeks. It takes a few seconds, best when nobody is there.

      Command line

      MR Studio comes with a command, mrstudio, that does from a terminal what the editor does with buttons. Presenting a table never needs it.

      Why you would want it

      For people who build tables and layers rather than present them. Once it is installed, any terminal, script or AI assistant that runs commands (Claude Code, Cursor, Codex) can work on your tables while the app is closed:

      • Check a table before a visit: mrstudio validate <table folder>
      • Bring data in with the same checks as Add data, or refresh it from a script every night: mrstudio data add <table> --target buildings --file buildings.geojson --write
      • Write a layer of your own and build it: mrstudio layer new energy-flows --site <table>, then mrstudio layer build --site <table>
      • Pack a table for another computer, or open one: mrstudio export and mrstudio import
      • Try a table in a browser without the app's screens: mrstudio dev --site <table>

      Type mrstudio --help for the whole list. The MR Studio MCP server finds the command inside the app by itself, so it works without this too.
