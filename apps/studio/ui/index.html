    Displays

      Display

        Each display keeps its own colour. Changes show at once on a running session and are saved as you make them.

        Colour

        Double-click a slider to put it back. Saturation and contrast are what usually help on a projector.

        Layer intensity

        How strongly each layer is drawn on the table. Remembered for this site.

        Projector calibration

        1. Start the tool. It appears on the table and names ten corners of the model, one at a time.
        2. Move each projected marker with the mouse or the arrow keys until its light sits on that corner of the physical model. Skip a corner you cannot find.
        3. From six corners on, the model is drawn through the solved camera, so you can see whether it lands.
        4. Save on the table. The calibration is kept in the site folder for this site.

        Updates

        While presenting, Ctrl Shift + E editor, S this window, Q quit.

        New site

        The site starts with a base map and sunlight. Everything else is added in the editor, and these values can be changed later in site.json.
